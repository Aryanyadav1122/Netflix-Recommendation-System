# Netflix Recommendation System

A Netflix content analysis and recommendation system built using Python, Pandas, Scikit-learn, Streamlit, and Machine Learning.

## Features
- Netflix dataset analysis
- Content-based recommendation system
- Interactive Streamlit web app
- Genre and rating analysis
- Movie and TV show filtering

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Matplotlib

## Run Locally

```bash
streamlit run app.py
